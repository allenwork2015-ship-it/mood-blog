拾光手札手機修改修正版

修正：舊照片快取讀取失敗，不再阻擋文字修改保存到待傳佇列；待傳區顯示已快取舊照片；同步錯誤顯示請求階段；更新離線網站快取版本。

部署：先下載 GitHub 原本的 index.html 與 sw.js 備份；將本包兩個同名檔案上傳到 mood-blog 儲存庫根目錄覆蓋。其他檔案保持原樣。等待 GitHub Pages 部署成功，手機正常重新整理一次，再按 Google Drive 連線及上傳日記。不要清除網站資料。

本修正版沒有修改待傳資料庫名稱、結構或刪除待傳資料。只能防止之後的照片快取錯誤阻擋儲存，無法恢復從未成功保存且已關閉的修改。

已驗證 JavaScript 語法及模擬舊照片讀取失敗時的儲存行為；未在你的手機與 Google 帳戶上完成實際上傳測試。Load failed 的底層網路原因仍需部署後的詳細錯誤確認。
