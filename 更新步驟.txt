拾光手札 Ver 17｜更新與回復步驟
更新日期：2026-10-20

更新前
1. 確認各裝置待傳日記已同步；尚未同步者先保留原瀏覽器資料並匯出備份。
2. 備份日記資料夾，保留 Ver 16 回復包。
3. 測試版草稿與待傳不會自動搬入正式版。已保存到日記檔案或已完成雲端同步的內容，可由正式版讀取。

GitHub Pages 更新
1. 解壓縮 Ver 17 完整 ZIP。
2. 將包內全部檔案與 assets、webfonts 資料夾，放回原 GitHub Pages 相同目錄；不要只換 index.html，也不要多包一層資料夾。
3. 一次提交完整更新，等待 GitHub Pages 部署完成。
4. 關閉舊拾光手札分頁後重新開啟原網址。頁尾及設定應顯示 Ver 17；若仍是 Ver 16，連網重新整理後再確認。
5. 使用原網站及瀏覽器，設定、待傳與備份沿用原儲存位置；請勿清除網站資料或改用無痕模式處理原待傳內容。
6. 首次連網完成快取後可重新離線開啟程式；這不會自動下載全部雲端日記和照片。

電腦本機更新
完整解壓縮到獨立程式目錄，開啟 index.html，再選日記資料夾。
保留 assets、webfonts 與所有 JS／CSS 檔。Google Drive 登入仍需原已設定 OAuth 的 HTTPS 網址。
本機 file:// 不啟用網站離線快取；若變更網址或程式路徑，瀏覽器儲存內容是否共用由瀏覽器決定，不能代替原來源的待傳備份。

更新後簡短確認
・先以日記副本確認舊日記文字、照片與心情正常，再切換日記本。
・修改文字，新增及刪除頁面；移動、縮放、旋轉照片，重新開啟確認結果。
・手機直向與橫向各翻頁一次；電腦同步後，手機刷新確認同篇內容。
・有異常時保留頁面，從設定→系統紀錄匯出效能診斷，附裝置、時間與操作步驟。

需要回復 Ver 16 時
先保存或匯出未同步修改，再用 Ver 16 回復包完整還原原程式目錄，關閉舊分頁並連網重新開啟。
Ver 16 不提供日記本編排操作；回復程式不等於回復日記內容。請保留更新前日記備份，避免用舊版修改需要保留的新編排。
不要清除網站資料；不要刪除 .shiguang-sync.json 或 .shiguang-backups。

範圍
本包為正式發布程式與部署資料，不包含個人日記、照片、帳號或權杖。
尚未代為上傳 GitHub Pages。共享日記、相片回顧與完整離線閱讀未新增。
